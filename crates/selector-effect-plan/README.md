# Static effect planning

This crate composes admitted method effects and paired change influence. Query
selection does not use it yet. A content seal binds the exact facts, graph,
runtime, inputs, complete root catalogue, contracts, canonical member authority,
capsules and change seeds. The seal does not establish the truth of producer or
linker claims; those require an admitted-world constructor and checked receipts.

Missing methods, source opacity, incomplete callable sets and unresolved aliases
retain uncertainty. Compiler contexts, root ordinals and allocation sites do not
establish process or classloader isolation. Class initialization, implicit VM
exceptions, synchronization, external effects and code observation remain
separate proof channels. Runtime-state buckets cannot hide ordinary VM-mutated
fields, and type-only exceptions do not establish fresh object ownership.

The planner uses flat CSR/SCC tables, a root bit matrix and bounded reusable
scratch. It charges owned transport, decoded tables and planner capacities.
Resource exhaustion returns an error instead of a partial finite certificate.
Source/native identities require an exact compiler-to-ABI and canonical storage
linker; matching names or node hints do not discharge another row's uncertainty.

Callable code and capture payloads are independent of heap-region precision.
Escaping a fresh value must not erase a known callable implementation. Local
payloads may be instantiated separately for different entry analyses, while
actual shared heap slots join payloads across the entire catalogue. Repeated
creations and recursion join finite payload cells without allocation histories.
Creation alone never activates a deferred body.

An admitted default SAM bridge runs its actual method capsule with a singleton
cell containing the original payload as receiver. It does not inherit the
creator's lexical receiver or capture ABI. The bridge's own reads, writes,
initialization and code observations remain in the composed closure; an absent
or mismatched bridge stays unknown. Equal arity alone is not a SAM adaptation.

Paired omission requires both revisions and the same complete stable catalogue.
Ambient/bootstrap/background entry effects need an explicit admitted contract;
a catalogue hash alone does not rule them out. The current tests use controlled
admitted-IR protocol worlds and do not establish real JVM omission authority.
