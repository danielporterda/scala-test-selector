This crate projects source-local may-effects over sealed facts and graph. It
scans every operation of every source-owned recipe and preserves existing
uncertainty independently of finite effect rows. Missing source/native recipes
are explicit ALL-TOP subjects, never empty capsules. Metadata-only hierarchy
diagnostics stay recorded without becoming execution effects.

One owner holds flat numeric tables. Source strings and operands are borrowed;
per-body value scratch is reused. Conservative preflight budgets include output,
sidecars, scratch and peak vector growth. Subjects, sites, members and source
provenance retain artifact-local IDs under exact facts/graph pins. Source/native
member aliases require a separately admitted linker proof.

Callable creation is separate from execution. BindCallback emits a capture-cell
creation; InvokeCallback carries a symbolic receiver/argument/capture/local value
and an admitted SAM key. Calls have explicit result cells, while Copy, Return and
canonical member/array loads/stores retain callable flow. Without an exact SAM
identity the invocation remains TOP. A body parameter count is not a FunctionN
ABI certificate. Opaque constants and unresolved loads never become known code.
Closure escape still leaves independent escape/flow uncertainty open.

This crate has no API that clears source guards using a classfile name, source
line, tuple count, callback ordinal or matching source hash. Compiled-source
correspondence lives in selector-compiled-products; an independent consumer must
admit complete compiled effect coverage before choosing that authority.
